
# Talent Community

A regional digital platform connecting talented individuals with real-world challenges published by organizations and businesses.

## Problem
Talented individuals have limited opportunities to showcase practical skills and discover relevant opportunities. Organizations also need better ways to discover talent and present practical challenges.

## MVP Features
- User authentication and role-based access
- Talent profiles and portfolios
- Organization registration and verification
- Challenge publication and discovery
- Applications and application tracking
- Basic project tracking and showcase

## Technology Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB + Mongoose

## Project Structure
- `client/` - Frontend application
- `server/` - Backend API
- `docs/` - Architecture and technical documentation
